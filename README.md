# Команды-шпаргалки для github



**Утилиты**

* Переход к пути
  ```
  git cd <путь>
  ```

* Статус
  ```
  git status
  ```

* Move/force/message
  ```
  -m
  ```

* Установить конфиг на устройство(Имя)
  ```
  git config --global user.name "Имя Ф."
  ```
* Установить конфиг на устройство(Почта)
  ```
  git config --global user.email "email"
  ```



**Создание git репозитория**

* Инициализация
  ```
  git init
  ```

* Закрепление репозитория
  ```
  git remote add origin <URL>.git
  ```
  
* Переименование(не принудительное) ветки
  ```
  git branch -m main
  ```
  
* Подтянуть с GitHub файлы:
  ```
  git pull origin main
  ```


  
**Работа с изменением git репозитория**

  * Выбрать файлы для сохранения
  
    - Сохранить все изменившиеся:
    ```
    git add .
    ```
    - Сохранить конкретные:
    ```
    git add file.cpp
    git add file.h
    git add folder
    ```
      - Убрать из сохранения всё:
    ```
    git reset .
    ```  
    - Убрать из сохранения файл / папку:
    ```
    git reset extra_file.cpp
    ```
      
  * Коммит:
    ```
    git commit -m "что было сделано?"
    ```
    
  * Отправить сохранения в ветку:
    ```
    git push origin <имя ветки, в которую отправляете>
    ```
    
  * Подтянуть изменения с Github
    ```
    git pull origin <имя ветки, в которую подтягиваете>
    ```



**Скачивание уже существующего репозитория с гитхаб**

  ```
  git clone <URL>.git
  ```



**Разработка**

* Создать ветку:
  ```
  git branch dev
  ```

* Перейти в ветку:
  ```
  git checkout dev
  ```
